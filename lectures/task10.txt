Задание 10: триггеры
Описание
Система инвентаризации уже во многом функциональна. Осталось ответить на один вопрос: каким образом товары из резерва заказа попадают в накладную на доставку.

Как только все товары заказа оказались в резерве, система должна изымать их оттуда и переносить в доставку. Также должен меняться статус заказа с pending на packing. Для случая, когда все товары есть на складе доставки, такая ситуация не представляет проблемы, потому что inventory_manager имеет доступ до статуса orders и также может создавать накладную на доставку.

В случае, когда товар из заказа приезжает с другого склада, разгрузкой занимается worker. У worker нет прав на смену статуса заказа. Также он может не обладать правами и на создание накладной на доставку (впрочем, этого условия у нас не было).

Давайте попробуем решить данную проблему с помощью триггеров. Нам нужно создать 2 триггера:

триггер на обновление статуса заказа с processing на pending
триггер на обновление резерва с отслеживанием изменения количества
Первый триггер должен проверять, что все товары в нужном количестве в резерве. И если это так, то запускается процедура создания доставки. Это соответствует сценарию, когда все товары есть на целевом складе, и заказ полностью обработан inventory_manager.

Второй триггер должен проверять, что статус заказа pending и что все товары в нужном количестве в резерве. Если это так, то запускается процедура создания доставки. Это соответствует сценарию с перемещением товара из другого склада.

Процедура создания доставки включается в себя следующие шаги:

Создание delivery
Создание delivery_item для каждой позиции в резерве
Удаление товаров из резерва
Смена статуса заказа на packing
Задачи
Написать триггер на обновление статуса заказа для создания доставки
Написать триггер на обновление резерва для создания доставки
Бонусная задача (необязательно)
Для полного функционирования системы нам остается только добавить проверку, что порог стоимости для перемещения достигнут. Мы также можем сделать это триггером. У нас уже есть команда start shipping. Какой триггер подойдет для проверки условия на суммарную стоимость перемещения?
